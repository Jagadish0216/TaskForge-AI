# TaskForge AI — Application Screenshots Guide

This directory documents the visual captures of the **TaskForge AI** deployed web application.

---

## 📸 Recommended Portfolio Captures

When presenting TaskForge AI in portfolio demonstrations or documentation, capture high-resolution desktop screenshots (1920x1080) of the following key interfaces from the live deployment ([https://taskforge-ai-psi.vercel.app/](https://taskforge-ai-psi.vercel.app/)):

### 1. `01-landing-page.png`
- **View**: Public Landing Page (`/`).
- **Highlights**: Dark slate engineering aesthetic, live system status badge, feature highlights, and demo credential login buttons.

### 2. `02-executive-dashboard.png`
- **View**: Main Dashboard (`/dashboard`).
- **Highlights**: Task completion charts, project status breakdown, workspace metrics, and active project context switcher.

### 3. `03-kanban-board.png`
- **View**: PULSE Project Board (`/projects/1/kanban`).
- **Highlights**: 5-column Kanban layout (`Backlog`, `To Do`, `In Progress`, `In Review`, `Done`), 10 canonical tasks, priority badges, and drag-and-drop card states.

### 4. `04-ai-mission-control.png`
- **View**: AI Mission Control Workspace (`/ai-workspace`).
- **Highlights**: Risk Radar capacity bottleneck analysis and Sprint Planner prompt interface.

### 5. `05-project-copilot.png`
- **View**: Project AI Co-Pilot Tab (`/projects/1/ai-copilot`).
- **Highlights**: Structured AI sprint recommendation cards, task breakdown estimates, human-in-the-loop task selection checkboxes, and raw JSON developer toggle.

### 6. `06-admin-control-surface.png`
- **View**: Platform Admin Portal (`/admin`).
- **Highlights**: Platform audit log table, global user list, role-gated admin operations, and system health status.

---

## 📌 Capture Guidelines
- Use Dark Mode browser theme for consistent styling.
- Ensure demo user credentials (`manager@demo.taskforge.local` or `admin@demo.taskforge.local`) are active when capturing authenticated views.
